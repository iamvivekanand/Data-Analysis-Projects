\# Gaming Market Intelligence Engine



An enterprise-grade Conversational Business Intelligence (BI) engine powered by \*\*DuckDB\*\*, \*\*Google Gemini\*\*, and \*\*Plotly\*\*. Designed for gaming studio leadership, market analysts, and publishers to query multi-decade sales data in natural language.



\---



\## Key Enterprise Features

\- \*\*Deterministic SQL Guardrails:\*\* Strict regex security layer preventing data mutation (`DROP`, `DELETE`, `UPDATE` blocked).

\- \*\*Multi-Turn Analytical Memory:\*\* Maintains conversation state for contextual follow-up drill-downs.

\- \*\*In-Memory Analytical Engine:\*\* DuckDB integration executing sub-second aggregations over large CSV catalogs.

\- \*\*Client Deliverable Formats:\*\* Instant one-click exports to CSV and Excel (`.xlsx`).

\- \*\*Dynamic Visual Storytelling:\*\* Automated selection of Plotly charts (Bar, Line, Pie, Scatter) based on question semantics.



\---



\## Architecture \& Tech Stack

\- \*\*Frontend / Dashboard:\*\* Streamlit

\- \*\*Analytics Database:\*\* DuckDB (In-Memory)

\- \*\*Visuals:\*\* Plotly Express

\- \*\*LLM Engine:\*\* Gemini 3.8 Flash

\- \*\*Data Engineering:\*\* Pandas, OpenPyXL
